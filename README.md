# Wedding Stage — Desain 1: Garden Pavilion Romantis

Panggung pernikahan 3D di browser (Three.js, satu file `index.html`).
Gazebo putih berkubah di pulau kecil di tengah kolam koi, dengan jembatan bunga, lentera, dan taman sakura.

- Geser untuk memutar, scroll/cubit untuk zoom
- Ganti warna bunga, suasana (siang/senja/malam), dan sudut kamera dari panel bawah
- Ikon pensil di kanan atas untuk mengubah nama mempelai dan tanggal
